# 下一个生产力的代表

一个滚动叙事网页：从《共产党宣言》讲到 AI 神明，约 80 秒。向下滚动逐帧推进，或点左下角“有声播放”，画面会跟着口播、音效和配乐自动播放。

在线访问：https://donghuixin.github.io/FutureCapital/

![封面](cover.jpg)

## 结构

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面、滚动与播放控制、字幕 |
| `film.js` | 全部镜头的逐帧绘制（Canvas），以及口播时间到动画时间的映射 |
| `gods.js` | AI 神明场景：天际线、精英剪影、云层、圣光 |
| `audio/mix.m4a` | 口播 + 程序合成的音效与配乐，-14 LUFS |
| `assets/` | 程序生成的版画线稿、点阵大陆、GDP 数据、手部素材、产品标志 |
| `img/` | 五位看板娘的透明底图 |
